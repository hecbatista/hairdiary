# Brand artwork prompts

Prompts used to generate the Hair Diary app icon and splash artwork (issue #55). The generated images
were then refined by hand before export.

Palette: blush `#EAD9D1` (background), deep cocoa `#61524A` (symbol), rose taupe `#D7B5A6` (accent).

## Icon (full artwork)

```
App icon for "Hair Diary", an iOS hair-care journal app. One simple, bold symbol centered on a flat square: a single soft, flowing curl of hair whose shape also reads as an open journal or a bookmark ribbon. Flat vector style with a very subtle gradient, smooth confident curves, minimal detail. Warm, calm, premium palette: background solid blush #EAD9D1, symbol in deep cocoa #61524A with one accent in rose taupe #D7B5A6. The symbol fills about 60% of the canvas with generous padding and is still recognizable at 60x60 px. No text, no letters, no photorealism, no drop shadow, no border, no rounded corners. 1024x1024, opaque full-bleed background.
```

## Foreground layer (splash + Icon Composer)

```
The same curl-and-journal symbol, centered and isolated on a fully transparent background, deep cocoa #61524A with rose taupe #D7B5A6 accent, flat vector, no background, no text, 1024x1024 PNG.
```

## Alternative concepts

Used only if the curl doesn't land:

- A wide-tooth comb laid across a calendar page.
- A curl forming a heart.
